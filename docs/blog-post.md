# Azure 견적, 이제 한 화면에서 끝내자 — 실시간 가격 비교 웹앱 만들기

> Azure 공식 가격을 **실시간으로 불러와** 용량제·절약 플랜·예약 가격을 한 견적표에서 동시에 비교하는 웹 도구를 소개합니다.
>
> 👉 **바로 써보기: https://azure-cost-estimator.vercel.app**

---

## 이런 경험, 다들 있으시죠

Azure로 인프라를 설계하다 보면 항상 부딪히는 질문이 있습니다.

- "이 VM, 용량제로 쓰는 게 나을까 예약(Reserved)으로 사는 게 나을까?"
- "절약 플랜 1년이랑 3년이랑 얼마나 차이 나지?"
- "서비스가 20개인데… 하나하나 계산기 켜서 더해야 하나?"

공식 [Azure Pricing Calculator](https://azure.microsoft.com/pricing/calculator/)는 훌륭하지만, **여러 가격 모델을 나란히 비교**하거나 **수십 개 항목을 표 하나로 관리**하기엔 조금 답답합니다. 그래서 직접 만들었습니다.

**"한 표에서, 실시간 공식 가격으로, 다섯 가지 가격 모델을 동시에."**

---

## 무엇을 하는 도구인가

한 줄 요약하면 이렇습니다.

> **Azure Retail Prices API(공식 공시 가격)를 실시간 호출해, 여러 서비스의 가격을 견적표 하나에 모아 비교하는 단일 페이지 웹앱**

핵심 특징은 다음과 같습니다.

| 특징 | 설명 |
|------|------|
| 💰 **5가지 가격 모델 동시 비교** | 용량제(PAYG) · 절약 플랜 1년/3년 · 예약 1년/3년을 한 행에서 나란히 |
| 🔄 **100% 실시간 공식 가격** | 코드에 하드코딩된 단가 없음 — 전부 Azure 공시 API에서 조회 |
| 🧩 **39개 서비스 · VM 46개 시리즈** | VM, AKS, Disk, SQL, Storage, Cosmos DB, OpenAI 등 |
| 🌏 **44개 리전 (지역별 그룹)** | 한국/일본/미주/유럽 등 대륙별로 묶여 고르기 쉽게 |
| 📄 **CSV 일괄 입력 · 엑셀 내보내기** | 수십 개 항목을 한 번에 불러오고, 결과를 xlsx/CSV로 저장 |
| 🔒 **읽기 전용 · 데이터 미송신** | Azure 리소스를 만들거나 바꾸지 않고, 어떤 데이터도 외부로 보내지 않음 |

## 사용법 — 5분이면 충분합니다

### 1. 접속하기

브라우저에서 **https://azure-cost-estimator.vercel.app** 에 접속합니다. 화면 상단에 초록색으로

```
✓ 연결 정상
```

이 뜨면 준비 완료입니다.

> 상단에서 **기본 Region**(예: Korea Central), **통화**(KRW/USD 등), **기본 사용량(Hours)**(월 730시간 등)을 먼저 정해두면 이후 입력이 편합니다.

<!-- ![메인 화면](여기에-메인-화면-스크린샷) -->

### 2. 항목 추가하고 서비스 고르기

- **`+ 행 추가`** 버튼으로 견적 행을 만듭니다.
- **Service Category** 드롭다운에서 서비스를 선택합니다 (예: `Virtual Machine`).
- 서비스를 고르면 SKU 칸이 활성화됩니다. 클릭하면 **옵션 패널**이 열립니다.

### 3. 옵션 선택하기 (Azure 계산기와 동일한 항목)

옵션 패널에서 실제 Azure에서 고르는 것과 똑같은 항목을 선택합니다. 예를 들어 VM이라면:

- **운영 체제**: Linux / Windows / RHEL / SUSE
- **계층**: Standard / Spot / Basic
- **라이선스**: 라이선스 포함 / Azure Hybrid Benefit
- **시리즈 → 인스턴스**: 범주(범용·컴퓨팅·메모리·GPU 등) → 시리즈 → 구체적 SKU(예: `D4s_v5`)

선택을 마치면 **자동으로 가격이 조회**되어 그 행의 다섯 개 가격 칸(용량제·절약1Y·절약3Y·예약1Y·예약3Y)이 채워집니다.

<!-- ![옵션 패널](여기에-옵션-패널-스크린샷) -->

### 4. 수량·사용량 조정

- **Qty**: 인스턴스/리소스 개수
- **사용량(Hours)**: 시간제 서비스는 월 사용 시간(예: 730), 저장·전송 서비스는 사용량(GB 등)

값을 바꾸면 월/연 비용이 즉시 다시 계산됩니다.

### 5. 가격 모델 비교하기

각 행에는 5개 그룹이 색으로 구분되어 표시됩니다.

- **용량제(PAYG)** — 기준 가격
- **절약 플랜 1년 / 3년** — 시간당 환산 단가
- **예약 1년 / 3년** — 시간당 환산 단가

맨 아래 **Total** 행에서 견적 전체의 월/연 합계를 가격 모델별로 한눈에 볼 수 있습니다. "3년 예약으로 가면 전체 얼마나 절감되나?"를 바로 확인할 수 있죠.

> 💡 **팁**: 서비스에 따라 절약/예약 단가가 조회되지 않는 경우, `⊕` 버튼이나 헤더의 **채우기** 토글로 빈 칸을 용량제 값으로 채워 대략적인 비교를 이어갈 수 있습니다(수동 채움은 별도 표시됩니다).

<!-- ![견적표와 Total](여기에-견적표-스크린샷) -->

### 6. 여러 항목을 한 번에 — CSV 일괄 입력

항목이 수십 개라면 하나씩 클릭하는 대신 CSV로 한 번에 넣을 수 있습니다.

1. **CSV 양식** 버튼으로 템플릿을 내려받습니다 (서비스별 옵션 사전이 주석으로 들어 있어요).
2. 엑셀에서 필요한 행을 채웁니다: `Region, 분류, ServiceCategory, SKU, Qty, Hours, Options`
3. **CSV 불러오기**로 업로드하면 전 행의 가격이 자동 조회됩니다.

### 7. 결과 내보내기

**내보내기** 버튼을 누르면 서식이 적용된 **엑셀(xlsx)** 과 재업로드용 **CSV**가 함께 저장됩니다. 그대로 보고서나 제안서에 붙여 넣으면 됩니다.

<!-- ![엑셀 출력물](여기에-엑셀-결과-스크린샷) -->

## 알아두면 좋은 디테일

- **리전을 지역별로 그룹화** — 44개 리전이 아시아 태평양 · 미주 · 유럽 · 중동/아프리카로 묶여 있어 원하는 리전을 빠르게 찾습니다.
- **리전 미제공 안내** — 특정 SKU가 선택한 리전에 없으면 `"이 리전에서 미제공 · 지원 리전 → …"` 형태로 **어느 리전에서 쓸 수 있는지**까지 알려줍니다.
- **열 보기 토글** — 필요 없는 가격 모델 열은 숨겨서 화면을 깔끔하게(데이터는 유지).
- **드래그로 순서 변경 · 행 복사/삭제** — 견적표를 자유롭게 편집.

## 기술적으로는 이렇게 만들었습니다

관심 있는 분들을 위한 요약입니다.

- **Vanilla JavaScript + Vite** — 프레임워크 의존성 없이 ES 모듈로 구성, Vite로 번들.
- **실시간 가격** — `https://prices.azure.com`의 Azure Retail Prices API를 호출. 단가는 전부 API에서 오고 코드엔 하드코딩이 없습니다.
- **CORS 없는 배포** — Vercel 서버리스 함수(`/api/prices`)가 같은 오리진에서 Azure API를 대신 호출해 브라우저 CORS 문제를 없앴습니다. (함수가 없는 정적 호스트에선 공개 프록시 체인으로 자동 폴백)
- **테스트 & 타입** — Vitest 회귀 테스트 + TypeScript 점진 도입으로, 서비스별 가격 매칭 로직을 자동 검증합니다.
- **읽기 전용 & 프라이버시** — Azure 리소스를 일절 건드리지 않고, 입력한 견적 데이터를 외부로 전송하지 않습니다(브라우저 안에서만 처리).
